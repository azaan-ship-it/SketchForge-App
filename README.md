# SketchForge

**Draw it. Guess it. Win it.**

A ByteForge Studios app.

## Download

**[Download SketchForge for Windows](https://github.com/azaan-ship-it/SketchForge-App/releases/latest/download/SketchForge-Setup-1.0.0.exe)**

Or grab it from the [Releases](https://github.com/azaan-ship-it/SketchForge-App/releases) page. Windows may show a SmartScreen warning because the app isn't signed yet: click **More info → Run anyway**.

## Play on the web

**[Open SketchForge in your browser](https://sketchforge-nuk8.onrender.com)**, no install needed. (The free server sleeps when nobody is using it, so the first load can take about a minute.)

## Features

- Make a party, pick a stickman avatar, and take turns drawing while everyone guesses
- Custom words from the host, team mode and speed rounds
- Full drawing tools, best-drawing vote and stickman dances
- Accounts and XP, end-of-game replays, music and themes
- Play online, or host a game on your PC for friends on the same Wi-Fi
